# Modrinth Client

Неофициальный Нативный Android-клиент для [Modrinth](https://modrinth.com) в стиле **Material 3 Expressive**.

## Что умеет

- Поиск модов через официальный API (`api.modrinth.com/v2`)
- Показывает иконку, название, описание, автора и количество скачиваний
- Вкладки типов контента: **Моды / Ресурспаки / Шейдеры**
- Расширенные фильтры в нижней шторке: загрузчик (Fabric, Forge,
  NeoForge, Quilt), 12 категорий, 4 варианта сортировки
- Работа без обходов РКН
- Бесконечная прокрутка: страницы по 25 штук через `offset`
- Быстрый фильтр по версии Minecraft
- Список версий проекта: номер, загрузчики, размер файла
- Волнистый индикатор прогресса в стиле M3 Expressive
- Скачивание `.jar` прямо в `Downloads/ModrinthClient` на телефоне
- Настоящее GPU-размытие: фон под шапкой и при открытии шторок

## Как сделано размытие

Список записывается в `GraphicsLayer` через
`Modifier.drawWithContent { layer.record { ... } }`, причём вместе с фоном —
поэтому копия непрозрачная и чёткий текст сквозь шапку не просвечивает.
Шапка рисует эту копию с `Modifier.blur(32.dp)` и приглушает её матовым
скримом. На Android 12+ это `RenderEffect`, вся работа на GPU.

Слои включаются только когда список прокручен и ни одна шторка не открыта.
На Android 8–11 `Modifier.blur` — no-op: шапка просто остаётся плотной.


## Дизайн

- Язык Material 3 Expressive: крупные скругления (28–36 dp), плакатная
  типографика с тяжёлыми начертаниями, пружинные анимации, «мягкие» контейнеры
- Динамические цвета Material You (Android 12+) с запасной зелёной палитрой
- Тёмная и светлая темы

> Почему не `MaterialExpressiveTheme`? Этот API стал публичным только в
> `material3:1.5.0-beta02`, а она требует `compileSdk 37` и AGP 9.1+ — то есть
> нестабильную цепочку инструментов. Поэтому Expressive-стиль собран на
> стабильном `material3:1.4.0` через явные `Shapes` и `Typography`.


## Сборка

Проект собирается на GitHub Actions — локальный Android SDK не нужен.

```
git push origin main      # соберёт APK и приложит артефакт
git push origin v1.0.0    # дополнительно создаст GitHub Release
```

## Установка

Скачай APK из раздела **Releases** и открой на телефоне (нужно разрешить установку
из неизвестных источников). APK подписан debug-ключом — этого достаточно для
сайдлоада.

## Разрешения

- `INTERNET` — запросы к API и загрузка файлов
- `WRITE_EXTERNAL_STORAGE` — только для Android 8–9; на Android 10+ файлы
  пишутся через `MediaStore` вообще без разрешений

## Стек

Kotlin · Jetpack Compose · Material 3 Expressive · OkHttp · Coil · org.json

## Подпись релиза

Release-APK подписывается собственным ключом (`release.keystore`, PKCS12).
Сам ключ и пароли в репозиторий не попадают — они лежат в секретах GitHub
Actions: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.

Локальная сборка: положи `release.keystore` в корень проекта и задай
`KEYSTORE_PASSWORD` / `KEY_PASSWORD` в окружении. Если ключа нет, release
соберётся неподписанным — это нормально для форков и pull request'ов.
